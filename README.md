# ELDEN RING: ASCENSION

Roguelite cards for the Lands Between, by Lord Bink. Version 3.4.1.

Beat a boss for the first time and choose 1 of 3 cards. Each card is a permanent power for
that character; picking it again raises its level up to V. 261 cards, 9 Paths, 31 Signature
cards, 18 Keystones and 10 ultra-rare Prismatic cards. Offline only, with its own save file,
loaded by Mod Engine 3.

This repository is the full source of the mod's native DLL and its data generators.
Players should download the ready mod from Nexus Mods; this is for anyone who wants to read
or build the code.
